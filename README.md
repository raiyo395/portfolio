## Featured Projects

### Client Portal — *Flagship, Full-stack*
One place for freelancers and their clients. Admins create projects and milestones. Clients log in, track progress, approve milestones or request changes, and download files.

Built with React, TypeScript, Tailwind, Vite, React Router, Vitest, and Supabase (Auth, Postgres, Storage, Row Level Security). Includes role-based access, decision history, and private file storage.

Hit **Try as Admin** or **Try as Client** on the login page, no sign-up needed. The demo runs on fake data and resets every night, so please don't upload real documents.

**Live demo:** https://client-portal-seven-indol.vercel.app/  
**Source:** https://github.com/raiyo395/client-portal

### Nexus — *Web3*
A wallet dashboard that shows every step of a transaction (pending, confirmed, rejected) so users never have to guess what happened. Runs on Sepolia testnet, so no real money is involved.

Built with React, TypeScript, wagmi, viem, Tailwind, and Vite. Handles account and network changes and multiple wallet providers.

**Live demo:** https://nexus-chwr.vercel.app/  
**Source:** https://github.com/raiyo395/nexus
